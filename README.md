🌍 Global Pulse

Your snapshot of a connected world.

Global Pulse is a responsive global dashboard that brings useful information from around the world into one place.

✨ Features

🌤️ Live weather for Santo Domingo

₿ Cryptocurrency prices

🌐 World clocks across six cities

💱 Currency converter, including Dominican pesos (DOP)

📊 Global financial market charts

🛢️ Brent and WTI oil market charts

📰 International news and science links

🎯 Number guessing game

🧠 Quick trivia

✨ Daily facts

🔌 Data Sources

Global Pulse uses public services and embedded widgets, including:

Open-Meteo

CoinCap

ExchangeRate-API

TradingView

Availability and update frequency depend on these providers.

🚀 Getting Started

Download or clone this repository.

Open index.html in a web browser.

Alternatively, enable GitHub Pages to host the dashboard online.
